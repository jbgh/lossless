lossless · architecture

Keep the tape.
Check out five records.

A work-context index for coding agents. The session file is append-only. Claims are a rebuildable HEAD. ask is checkout: ≤5 claims so the next turn does not repeat a failed, regress shipped work, or forget the answer. No LLM on retrieve. Age never disqualifies a claim.

01 — The loop

Write is push. Read is pull. Intelligence is split: the harness decides when to ask; lossless only packs. The agent obeys warnings.

harness

Agent / hooks

  • Grok, Claude, Codex, Pi, OpenCode
  • Skill: call ask before edits
  • Hooks copy JSONL on compact / stop
  • Watcher tails if a hook misses
→
lossless

Index + packer

  • No search string as the product
  • Work context → candidates → score → pack
  • Deterministic. Same packet across models
  • Empty pack is valid
→
agent again

Act on the packet

  • Read warnings first
  • Failed → do not repeat without evidence
  • Decision / constraint → do not silently undo
  • Optional GET / remember

03 — Write path

Always on. No query. Catch-up is idempotent by byte cursor. Own ask/remember/get_record I/O is skipped so the store does not ingest its packets.

W1

Copy the session file

Harness JSONL → owned raw/project/yyyy-mm/*.jsonl. Redact on the way in. Seal + zstd after session end.

W2

Excerpts

Monthly excerpts-YYYY-MM.sqlite. ~800–1600 chars. Tool bodies clipped. For GET, not for ask.

W3

Extract claims

Heuristics only: failed / decision / constraint / state / thread. Hash supersede. Symbols from text + path stems. jwt ↔ jsonwebtoken.

W4

Index

FTS5 body, path postings, symbol postings. Optional claim vector if an on-box embedder is attached. Markdown export is source of truth.

W5

remember

Bypasses heuristics. Still redacted, still on the raw tape under manual/. Writes a remember action.

05 — Ask algorithm

For You’s contract, not Phoenix: hydrate what this session just did, retrieve from several neighborhoods, score named jobs, pack for coverage, record what was served. p50 < 500ms, p95 < 2s. Hooks stay fast.

structure lexical dense tape job 1
A0

Request

question, goal, paths[], project | workspace_root, session_id?, limit_tokens

A1

Normalize

Project key, tokens, path keys (plus basename), identifier symbols. library / choice are not symbols. jwt is.

A2

Compile if thin

If no paths and <2 tokens: last user line + pathRE + recent claim paths from the owned session tail. Rich asks are never overwritten.

A3

Hydrate action tape

Last pack ids, GET/remember dwells, last-ask tokens — only on a continue (same question, anaphoric thin ask, or same files). A rich ask on a new path is a topic shift: no inherited Redis symbols.

A4

Profile

head if still empty. Else path / ident / prose. Mixes structure vs “sounds like.” Overlap weights do not change.

A5

Candidates ≤ 400

Union, not a scan. HEAD skips FTS and vectors.

FTSquestion ∪ goal, OR-quoted, 80
Path40 per key, 80 total
Symboljose, tokenBucket, jwt…
Type overlapfailed / decision / constraint
Vector kNNoptional, 120, claims only
Two-hoppathless: files the first pass hit

HEAD caps12 failed / 10 decision / 8 constraint
A6

Dedup + filters

Newest claim_hash. Drop older same-path conflicts (Jaccard ≥ 0.35). Drop a decision if a newer same-path failed shares topic (≥ 0.2). Filters, not scores.

A7

Features + score

Type, recency (half-life by type; constraint = 1), path/symbol Jaccard, min-max BM25, cosine, agree, graded overlap, dwell, served, OON. Stat mtimes on the current top 30 only. [verify] is ephemeral.

A8

Pack ≤ 5

Best failed-overlap first. Then score − 0.8 × max_sim. Type cap 2 if another type is uncovered. Diversity Jaccard 0.8. Evict so a job-1 failed cannot lose to the cap.

A9

Emit + record

Warnings cite ids that are in the packet. Then write ask / warn rows to the tape. Fail-open.

06 — Score

X’s shape: Σ wi P(actioni). Ours are jobs, not clicks. Weights multiply predicted usefulness, not raw counts.

P_fail    = failed_overlap + 0.25 × failed_weak
P_regress = shipped_overlap + 0.24 × shipped_weak
P_answer  = mix(type, path, symbol, bm25, vector, agree, recency)
           × (0.5 if off-path and the caller named files)

score = 4.0 × P_fail
       + 2.5 × P_regress
       + P_answer
       + 0.8 × dwell − 0.9 × served
       − 0.7 × stale
JobWhen it firesIf we miss
1 Do not repeat failedSame path, symbol, ≥2 content tokens, or cosine ≥ 0.55 on a failedAgent rebuilds the Redis limiter
2 Do not regress shippedDecision / constraint / state with path, symbol, or tokensAgent drops jose on the Edge
3 Answer the questionProfile mix. Path 1.8 / ident 1.6 / prose bm25=vector 1.3Agent cannot find “why we rejected X”

Strong overlap (path / symbol / 2 tokens / vector gate) force-packs and warns. One shared word is weak: score only. Recency never drops a candidate. A 10-month constraint still beats a 2-day unrelated failed.

07 — Action tape · For You analog

Phoenix represents the viewer as what they did, not a user id. We represent the session as ask / get / remember / warn. The next thin “ok continue” rebuilds the last work cluster. A new session is HEAD.

continue

Mix the tape

  • Same question tokens
  • Thin / anaphoric (“what were we looking at”)
  • Same path cluster as last ask
  • GET dwell boosts that claim
≠
topic shift

Do not inherit

  • Rich ask on a new file
  • No Redis symbols from last GET
  • Off-path P_answer × 0.5
  • Billing pack is warehouse only
