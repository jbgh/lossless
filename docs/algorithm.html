lossless · algorithm

How retrieve
picks five records.

The chat window is lossy. The session tape is not. lossless copies that tape, extracts a small index of durable claims, and on each ask checks out at most five of them for this goal and these files. No LLM on retrieve. Age never disqualifies a claim. Dense vectors are optional and unused in the live store today.

01 — Three layers

Same shape as git or a log stream: keep the objects, build indexes, check out a few records. Do not paste the stream into the next prompt.

tape

Full JSONL

  • ~/.lossless/raw/…
  • Every harness turn, forever
  • The model never reads this
claims

Index · cap 12

  • failed · decision
  • constraint · state
  • Rebuildable HEAD
pack

Checkout ≤ 5

  • context[] + warnings[]
  • This goal. These files.
  • This session’s tape only

Hooks write the tape. Extract indexes. ask is the checkout, not grep, not a summary.

02 — Three jobs, in this order

Fusion weights exist to express this order. They do not replace it. A prettier cosine hit in another file cannot beat a failed on the path you named.

job 1 · 4.0

Do not repeat failed work

  • Redis limiter already burned in staging
  • failed_overlap = 1 forces pack + warning
  • Packed first, before the type cap can starve it
job 2 · 2.5

Do not regress shipped work

  • jose, not jsonwebtoken, for Edge
  • Standing constraints (never log Authorization)
  • shipped_overlap = 1 warns
job 3 · mix

Answer the question

  • Path, symbol, FTS, optional vectors
  • Profile mix: path / ident / prose / HEAD
  • Cannot outrank jobs 1–2

03 — The loop

Write is push. Read is pull. The harness decides when to ask. lossless only packs. The agent obeys warnings.

harness

Skill + hooks

  • ask({ goal, paths, question })
  • Stop / PreCompact copies JSONL
lossless

Index + packer

  • candidates → score → pack 5
  • No LLM. Same packet every model.
agent

Obey, then act

  • warnings first
  • then implement

Intelligence is split. The model does not write a search query. It sends current work. lossless compiles lookups.

04 — Write: tape first, then a thin index

Catch-up is fail-open. Ingest is picky on purpose. Extract is allowed to drop almost everything; the tape still has the sentence.

01

Ingest the session file

Hook or watcher. Lstat then O_NOFOLLOW. Must be a regular .jsonl, size-capped. No /etc/passwd, no swapped symlink. Copy into ~/.lossless/raw/<owner>__<repo>/.

02

Parse harness JSONL

Grok / Claude / Codex / Pi / OpenCode. Skip system and developer roles. Skip nested tool_result. Skip own ask payloads (looksLikeOwnPayload). Clip lines over 8k instead of dropping the tail.

03

Extract durable sentences

Classify after Fold (curly apostrophes). failed only if grounded (path, tick, or proper noun) and not meta-talk. Paths are per-sentence plus the last few user turns, not the whole assistant message. Nearby does not glue auth.ts onto a later decoy.

04

Cap 12, pathful first

At most 5 per type. Failed dir-cap 2; decision/constraint dir-cap 5. FilterPaths drops abs/~/drive/.., .git, node_modules, keys, percent-encoded traversal. Leading-dot dirs like .github stay.

05 — Ask pipeline

One MCP/REST call. Target p50 < 500ms, p95 < 2s at 10k claims. Never scan the full project table.

01

normalize

project_key, question/goal tokens, path keys + basename, identifier symbols. Rich if a path is set or there are ≥2 tokens. Rich asks are never overwritten.

02

compile if thin, then hydrate

Empty question + goal: last 40 messages / 32k chars fill the query. Then load this session’s served / dwell / continue tape. Claims are shared by project; the action tape is this session only.

03

candidates · union · cap 400

FTS ∪ path ∪ symbol ∪ failed/decision/constraint. Pathless asks hop through files the first hits named. Empty union: last 8 faileds. Optional kNN if an embedder is attached.

04

drop

Extract-noise, fixture sessions, older same-path conflicts, decisions invalidated by a newer same-file failed on topic tokens (paths stripped).

05

features + score

No LLM. Sacred 4.0 failed-overlap + 2.5 shipped-overlap, then a path/ident/prose/HEAD mix.

06

pack 5 · type-cap 2 · warnings

Force the best job-1 failed first. Then coverage, then score. Blocking warnings on the packed hits.

07 — Features and score

Computed only on candidates. Weights scale these features, not raw counts of faileds. Same idea as X’s “weight × P(action)”, not “1 report = 468 likes.”

P_answer = mix(type, path, symbol, bm25, vector, agree, recency)

08 — Pack: the checkout

Sort by score, then created_at, then id. Then walk. Hard cap 5. At most 2 per type if another type is still available.

01

Drop oon states

Ask named files, this claim shares none. Skill-state on SKILL.md cannot take a slot from auth.ts.

02

Drop ungrounded faileds

No caller path, no symbol, no failed-overlap, no hop. Weekday chatter dies. Two-hop Redis on an inferred file stays.

03

Force the best failed_overlap

Job 1 cannot lose to the type cap. Then repeatedly take max(score − 0.8 × similarity to packed). Skip hash or text Jaccard ≥ 0.8. Type-cap 2.

04

evictFailed, then emit

Swap in a path/symbol failed-overlap if it missed the pack. Then ≤5 hits and blocking warnings.

Packed hitWarning
failed + failed_overlapA prior attempt failed (see id). Do not repeat without new evidence.
decision + shipped_overlapExisting implementation may already cover this (see id).
constraint + shipped_overlapA standing constraint applies (see id).

If a tagged file’s mtime is newer than the stored claim, text is prefixed [verify] for this response only. Not persisted. Claims are shared by project. The action tape (served / dwell / continue) is only the asking session.

10 — What this is not

not mem0

We keep the tape

  • Mem0 LLM-extracts facts and throws the transcript away
  • Failed approaches and tool results survive here
  • Claims are HEAD. You can rebuild them
not x for you

We do not predict clicks

  • No Thompson-sampled cold start
  • No semantic-id slate diversity on a pathful ask
  • A checkout on auth.ts should stay on auth.ts
not grep

We do not dump the stream

  • Never listActive the whole project
  • Empty pack is valid
  • The model does not write a search string
observe

inspect is the loop

  • lossless inspect — tape vs claims vs cursors
  • --ask — score / path / fail / ship / why dropped
  • --jsonl — extract keep/skip on a session file
  • --prune — drop hook-test ingest, supersede extract-noise
